# Phase B typography previews

Generated by `cargo run -p iceberg-widget -- --screenshot=../docs/phase-b` from `app`.

These are offscreen renders over a neutral review backdrop, not a design sign-off.
The real widget is a transparent layered window on the desktop.

- `card-100.png`, `card-150.png`, `card-200.png`: Card mode at 100, 150 and 200% scale
- `lyrics-100.png`, `island-100.png`: the other two modes
- `state-*.png`: empty, loading, no lyrics, instrumental, unsynced
- `card-arabic-100.png`: Arabic shaping and RTL with the normal system fallback
- `font-*-100.png`: the same Card at 100% with each stock family, using normalized metrics
- `bench-*.json`: release measurements at each scale

Every Card preview stays 388 x 245 at 100%: optical size and baseline are normalized,
while line spacing stays on the user's line-height grid. See `RESULTS.md` for numbers.

Stock families: Lato, Poppins, Abril Fatface, Barlow Condensed, Amatic SC,
Space Mono, Varela Round, Lobster. All are OFL 1.1; licenses are in
`app/assets/fonts/<family>/OFL.txt`.

## What Phase D added

- A real companion process at `app/settings`, built as a Tauri 2 window with a vanilla TypeScript/Vite frontend. It has no UI framework, no component kit, no icon package, and no web fonts.
- A persistent per-session named-pipe connection between the settings backend and the widget. The widget owns the pipe server; the settings holds one connection for its lifetime and sends config/status/font events over it.
- IPC commands for config reads/writes, status, presets, settings open/close, reveal, font invalidation, visibility, and hotkey/tray actions.
- One shared schema in `app/core/src/ipc.rs`; config changes are validated and saved by the widget before the `ConfigChanged` response.
- Settings sections: Appearance, Typography, Layout, Lyrics, Playback, Hotkeys, About. There is no separate command palette, fake widget, or dashboard stat row.
- Native preset/surface thumbnails generated by `cargo xtask` from the same renderer and demo scene.
- Native font specimens for the story-style picker, generated by the widget's cosmic-text/swash path at 320 × 180. The settings receives only the PNG bytes; the browser does not imitate the widget's text rendering.
- Font upload through a native file dialog, copied under a generated name in the app's own fonts folder, then invalidated in the widget.
- Editable global hotkeys with backend syntax validation.
- Settings single-instance guard, widget single-instance guard, and a widget path next to the settings executable.

## What Phase E added

- Tray menu entries for settings, click-through, and mode cycling.
- Global hotkeys: show/hide, click-through, ±100 ms lyric offset, cycle mode, three-second quick peek, and open settings.
- Edge snapping and a per-monitor remembered position. The current monitor's position is saved after a move settle; changing the global anchor/offset clears stale per-monitor positions.
- Pause auto-hide (0 disables), fullscreen auto-hide through a WinEvent foreground hook, reduced motion, battery saver, optional start with Windows (HKCU `Run`, no admin), and click-through live updates.
- Mode selection in Layout and live live-preview config application.
- A project tray icon from `app/assets/icons/iceberg.ico`.
- Native release packaging and an NSIS installer through `cargo xtask package`; the sidecar widget and `assets` are bundled with Tauri resources.
- CI/release/security workflows updated for the settings frontend, workspace, sidecar, portable ZIP, and checksums.

## Settings behavior notes

- The focus refresh is guarded against an edit starting while it is in flight. This fixed a real early bug where a click during the refresh could be overwritten and never saved.
- The settings bootstrap opens the widget preview explicitly. The pipe no longer treats connection teardown as a close; a crash or missing explicit close still restores the preview via the connection's `opened` state.
- The font preview command starts a short-lived widget process with `--font-previews`, which returns before the single-instance check, event loop, tray, or settings IPC. It never writes the config or uses WebView fonts.
- Closing Settings sends `CloseSettings`, removes the demo track when appropriate, and leaves the widget in the tray. The settings process exits.
